# Industrial Training Kits — Phase 3

A modern, dynamic, and fully responsive web platform engineered for exploring specialized Industrial Training Kits. Built as part of the DecodeLabs Web Development Internship program, this platform provides interactive product exploration, live search filtering, modal popups, and accessibility-first user interface features.

## Key Features

- **Interactive Modal System:** Technical specifications and detailed module views accessible via custom popup modals.
- **Live Search & Category Filtering:** Instant client-side search indexing and category filtering built with vanilla JavaScript.
- **Dynamic Theme Switcher:** Light and Dark mode toggle with persistent UI states.
- **Fully Responsive Layout:** Mobile-first architecture engineered using modern CSS Grid and Flexbox layouts.
- **Accessibility & ARIA Support:** Screen reader friendly state management using semantic HTML tags and proper accessibility standards.

## Project Structure

- `task3.html` — Main UI markup featuring kit listings, dynamic sections, and modal dialog containers.
- `task3.css` — Modular stylesheets including responsive utility classes, theme variables, and grid components.
- `task3.js` — Client-side logic for search, category filtering, theme toggling, and modal controls.

## Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Variables, Flexbox, Grid, Media Queries)
- **Scripting:** JavaScript (Vanilla ES6+)
- **Hosting:** GitHub Pages

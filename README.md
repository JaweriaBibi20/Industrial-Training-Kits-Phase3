# 🚀 Industrial Training Kits — Phase 3

A modern, dynamic, and responsive web platform built for exploring and acquiring specialized **Industrial Training Kits**. Developed as part of the internship program at **DecodeLabs**, this platform offers an intuitive user experience for domain-specific engineering modules, features interactive search, detailed modal views, and responsive design layouts.

---

## ✨ Features

- **🔍 Live Search & Filter**: Real-time searching across various training kits and module names.
- **📦 Interactive Module Details**: Modal popups providing comprehensive overviews of kit components and curricula.
- **📱 Fully Responsive Design**: Built with a mobile-first approach, ensuring seamless rendering across desktop, tablet, and mobile displays.
- **🎨 Modern UI/UX**: Styled with sleek typography, modern color palettes, and polished UI elements.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic layout and structured UI elements.
- **CSS3**: Custom styling, Flexbox/Grid layouts, animations, and media queries.
- **JavaScript (ES6+)**: Dynamic DOM manipulation, modal interactions, and event handling.
